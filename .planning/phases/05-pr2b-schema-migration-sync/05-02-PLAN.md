## Goal
Implementare il **write path per-entità**: enqueue mutazioni in IndexedDB via `idb-keyval`, flush in ordine topologico FK al ritorno online (3× retry su 5xx, 409 → conflict UI binary, 401 → refresh + retry trasparente), toast persistente "N modifiche in coda", modal conflict non-dismissible. Wave 2: dipende dal foundation di 05-01 ma è indipendente da migration/UX nuove entità (plan 05-03/05-04 procedono in parallelo).

## Context summary
- Mutation entry shape: `{ op, entity, id, payload, ts, attempts, baseUpdatedAt }` (RESEARCH §5).
- Topological order **hardcoded** (falsifica Kahn's): `['tipi_utenza', 'banche', 'proprieta', 'inquilini', 'incassi_affitti', 'utenze']` (RESEARCH §5).
- Flush algoritmo: `while queue.length > 0` { sort + applyMutation(head) }, re-entrancy guard `_flushing`, retry 3× con backoff `[1s, 3s, 9s]` su 5xx, 409 → enqueueConflict + skip, 401 → refreshSession + continue (RESEARCH §5).
- Conflict queue FIFO, una modal visibile alla volta — copy italiano locked CONTEXT linea 162-167.
- Dual-write Phase 1 (DEC-012): durante questo PR ogni mutazione scrive **sia** entry per-entity (queue) **che** blob legacy via `salvaSubitoBlob()` come safety net. Blob removal viene a Phase 3 (+2 settimane).
- Alpine reactivity per `mutationQueueCount()` e `conflittoCorrente()` via counter slots `_mutationQueueVersion` / `_conflictVersion` (pattern PR2a `_snapshotVersion`, wiki/concepts/alpine-reactive-trigger-for-external-source.md).

    ```js
    // FK-aware topological order (LOCKED — hardcoded falsifica Kahn, vedi RESEARCH §5)
    // Se in futuro una self-FK viene aggiunta, sostituire con Kahn's algorithm.
    // ENTITY_FLUSH_ORDER definito come costante module-scope:
    // const ENTITY_FLUSH_ORDER = ['tipi_utenza', 'banche', 'proprieta', 'inquilini', 'incassi_affitti', 'utenze'];

    sortQueue(queue) {
      const ORDER = ['tipi_utenza', 'banche', 'proprieta', 'inquilini', 'incassi_affitti', 'utenze'];
      return queue.slice().sort((a, b) => {
        const ai = ORDER.indexOf(a.entity);
        const bi = ORDER.indexOf(b.entity);
        if (ai !== bi) return ai - bi;
        return a.ts - b.ts; // FIFO entro stessa entity
      });
    },

    async enqueueMutation(op, entity, id, payload, baseUpdatedAt = null) {
      const entry = { op, entity, id, payload, ts: Date.now(), attempts: 0, baseUpdatedAt };
      this.mutationQueue.push(entry);
      this._mutationQueueVersion++;
      try {
        if (typeof idbKeyval !== 'undefined') {
          await idbKeyval.set('mutationQueue', this.mutationQueue);
        }
      } catch (e) {
        this.pushErrore({ message: 'enqueue persist: ' + (e?.message || 'unknown'), severity: 'warn' });
      }
      // Trigger immediato se online
      if (this._isOnline) {
        this.flushMutationQueue();
      }
    },

    async applyMutation(entry) {
      // entry = { op, entity, id, payload, baseUpdatedAt, ... }
      // snake_case payload: il caller di enqueueMutation deve già passare snake_case (matcha DDL).
      if (entry.op === 'insert') {
        const { error } = await sb.from(entry.entity).insert(entry.payload);
        if (error) throw Object.assign(new Error(error.message), { status: error.code || error.status });
      } else if (entry.op === 'update') {
        let q = sb.from(entry.entity).update(entry.payload).eq('id', entry.id);
        if (entry.baseUpdatedAt) {
          q = q.eq('updated_at', entry.baseUpdatedAt); // optimistic concurrency — 0 rows = 409
        }
        const { data, error, count } = await q.select('*', { count: 'exact' });
        if (error) throw Object.assign(new Error(error.message), { status: error.code || error.status });
        if (entry.baseUpdatedAt && (!data || data.length === 0)) {
          throw Object.assign(new Error('updated_at mismatch'), { status: 409 });
        }
      } else if (entry.op === 'delete') {
        // soft-delete: set deleted_at; hard-delete via .delete() solo per tipi_utenza
        const { error } = await sb.from(entry.entity).update({ deleted_at: new Date().toISOString() }).eq('id', entry.id);
        if (error) throw Object.assign(new Error(error.message), { status: error.code || error.status });
      } else {
        throw new Error('Unknown op: ' + entry.op);
      }
    },
    ```

       ```js
       async flushMutationQueue() {
         if (!this._isOnline) return;
         if (this._flushing) return;
         this._flushing = true;
         try {
           while (this.mutationQueue.length > 0) {
             const sorted = this.sortQueue(this.mutationQueue);
             const entry = sorted[0];
             try {
               await this.applyMutation(entry);
               const idx = this.mutationQueue.findIndex(e => e.ts === entry.ts && e.id === entry.id && e.entity === entry.entity);
               if (idx >= 0) this.mutationQueue.splice(idx, 1);
               this._mutationQueueVersion++;
               if (typeof idbKeyval !== 'undefined') await idbKeyval.set('mutationQueue', this.mutationQueue);
               this.lastPushAt = new Date().toISOString();
             } catch (e) {
               const status = e?.status || e?.code;
               if (status === 409 || status === '409' || /updated_at mismatch/.test(e?.message || '')) {
                 await this.enqueueConflict(entry, e);
                 const idx = this.mutationQueue.findIndex(x => x.ts === entry.ts && x.id === entry.id && x.entity === entry.entity);
                 if (idx >= 0) this.mutationQueue.splice(idx, 1);
                 this._mutationQueueVersion++;
                 if (typeof idbKeyval !== 'undefined') await idbKeyval.set('mutationQueue', this.mutationQueue);
                 continue;
               }
               if (status === 401 || status === '401' || /jwt|token/i.test(e?.message || '')) {
                 const { error: rErr } = await sb.auth.refreshSession();
                 if (rErr) { this.pushErrore({ message: 'sessione scaduta', severity: 'warn' }); break; }
                 continue;
               }
               if (Number(status) >= 500) {
                 entry.attempts = (entry.attempts || 0) + 1;
                 if (entry.attempts >= 3) {
                   this.pushErrore({ message: `queue: ${entry.entity} ${entry.id} max retries`, severity: 'error' });
                   break;
                 }
                 await new Promise(r => setTimeout(r, [1000, 3000, 9000][entry.attempts - 1]));
                 continue;
               }
               // network / unknown: lascia in coda, esci silently
               this.pushErrore({ message: `queue: ${e?.message || 'unknown'}`, severity: 'warn' });
               break;
             }
           }
         } finally {
           this._flushing = false;
         }
       },
       ```

    ```js
    async enqueueConflict(entry, e) {
      let serverRow = null;
      try {
        const { data } = await sb.from(entry.entity).select('*').eq('id', entry.id).maybeSingle();
        serverRow = data;
      } catch (_) { /* ignore — toast still shows with null serverPayload */ }
      this.conflictQueue.push({
        entity: entry.entity,
        id: entry.id,
        localPayload: entry.payload,
        serverPayload: serverRow,
        nomeEntita: this.nomeUmano(entry.entity, entry.payload),
        ts: Date.now(),
      });
      this._conflictVersion++;
    },

    nomeUmano(entity, payload) {
      // Lookup tabella per "nome utente-visibile" — RESEARCH §6
      if (entity === 'proprieta') return payload?.nome || 'Proprietà';
      if (entity === 'banche') return payload?.nome || 'Banca';
      if (entity === 'inquilini') return payload?.nome || 'Inquilino';
      if (entity === 'tipi_utenza') return payload?.nome || 'Tipo utenza';
      if (entity === 'incassi_affitti') {
        const prop = (this.dati.proprieta || []).find(p => p.id === payload?.proprieta_id);
        return `Incasso ${payload?.mese || ''} su ${prop?.nome || 'proprietà'}`;
      }
      if (entity === 'utenze') {
        const tipo = (this.dati.tipi_utenza || []).find(t => t.id === payload?.tipo_id);
        return `Utenza ${tipo?.nome || ''} ${payload?.fornitore || ''}`.trim();
      }
      return entity;
    },

    async risolviConflitto(scelta) {
      const c = this.conflictQueue.shift();
      this._conflictVersion++;
      if (!c) return;
      try {
        if (scelta === 'mia') {
          // Force update senza updated_at gate
          const payload = { ...c.localPayload, updated_at: new Date().toISOString() };
          delete payload.id; // non aggiornare PK
          await sb.from(c.entity).update(payload).eq('id', c.id);
        } else {
          // Discard local: applica serverPayload allo stato Alpine
          this.applyServerEntity(c.entity, c.serverPayload);
        }
      } catch (e) {
        this.pushErrore({ message: 'risolvi conflitto: ' + (e?.message || 'unknown'), severity: 'error' });
      }
      // Riprendi flush per eventuali altre mutazioni in coda
      this.flushMutationQueue();
    },

    applyServerEntity(entity, serverRow) {
      if (!serverRow) return;
      // Mappa entity name → array chiave in this.dati (camelCase)
      const arrKey = entity === 'incassi_affitti' ? 'incassiAffitti' : entity;
      const arr = this.dati[arrKey];
      if (!Array.isArray(arr)) return;
      // Conversione snake → camel via adattaShape parziale
      const fake = { [entity]: [serverRow] };
      const adapted = this.adattaShape(fake)[arrKey];
      const mapped = adapted && adapted[0];
      if (!mapped) return;
      const idx = arr.findIndex(x => x.id === serverRow.id);
      if (idx >= 0) arr[idx] = mapped; else arr.push(mapped);
    },
    ```

## Threat model
- **Migration race condition multi-tab**: 2 tab dello stesso utente leggono entrambi `mutationQueue` al boot, scrivono entrambi su modifica → ultima write vince in IDB. **Mitigation** (R-NEW-4): ack che è basso rischio family-tier mobile single-window; entry "perse" recoverable via snapshot ring di PR1 (il blob legacy dual-write contiene comunque la modifica). Documentato in RESEARCH §4.
- **Auth bypass via stale JWT**: 401 catch → `refreshSession()` retry trasparente. Se refresh fallisce (refresh token expired) → break + toast "Sessione scaduta". L'utente è forzato a re-login; mutation queue persiste in IDB e verrà flushata al prossimo login successo.
- **Conflict modal bypass**: non-dismissible by design — no `@click` su overlay, no `@keydown.escape`. L'utente DEVE cliccare uno dei 2 bottoni. Se ci sono N conflitti in coda, la modal si ri-apre con il successivo dopo ogni risoluzione.
- **Data exfil via cross-user IDB**: `idb-keyval` usa un singolo IndexedDB database `keyval-store` per origin. Se 2 utenti diversi usano lo stesso browser, devono fare login → migration check `tipi_utenza.user_id` filtra correttamente; ma `mutationQueue` IDB residua del primo utente verrebbe **applicata col JWT del secondo** se non clear su logout. **Mitigation**: in `logout()` (app.js esistente) aggiungere `await idbKeyval.del('mutationQueue'); this.mutationQueue = []` — **DA AGGIUNGERE come bonus in T-05-02-03 o estrazione separata in plan 05-03**.

## Risks & mitigations
- **R4 (mutation queue corrompe stato)**: mitigato da FIFO order + 3× retry + persistent indicator. Se queue cresce >100 entry, considerare batch flush.
- **R-NEW-1 (private mode IDB)**: try/catch attorno a tutte le chiamate idbKeyval; fallback in-memory (perde entries su refresh ma no crash). Documentato; non blocker.
- **R-NEW-7 (Alpine reactivity gap su navigator.onLine)**: state slot `_isOnline` + listener `online`/`offline` bumping. Verificare visivamente che indicator scompaia entro 1s dopo "Network online" in DevTools.
